## Overview

**Nabil Amin Hridoy — Portfolio** is a modern, multilingual personal portfolio website and content management system built to showcase professional experience, technical skills, projects, services, education, certifications, and more.

Unlike a traditional static portfolio, this project includes a database-driven CMS that allows portfolio content to be managed dynamically through an administrative interface without modifying the frontend source code.

The application is built with a modern full-stack architecture using **Next.js, React, TypeScript, Prisma, and PostgreSQL**, with a strong focus on performance, maintainability, security, scalability, accessibility, and user experience.

## Environment Configuration

Create a local environment file from the provided example:

    cp .env.example .env

Configure the required environment variables.

### Database

    DATABASE_URL=postgresql://USER:PASSWORD@HOST:5432/DBNAME?schema=public&sslmode=require

### Authentication

    NEXTAUTH_URL=http://localhost:3000
    NEXTAUTH_SECRET=your-secure-secret

### Admin Bootstrap

    ADMIN_EMAIL=
    ADMIN_PASSWORD=
    ADMIN_NAME=

### Cloudflare Turnstile

    TURNSTILE_SITE_KEY=
    TURNSTILE_SECRET_KEY=

### SMTP

    SMTP_HOST=
    SMTP_PORT=465
    SMTP_USERNAME=
    SMTP_PASSWORD=
    SMTP_FROM=
    SMTP_FROM_NAME=

> The actual `.env` file must never be committed to Git.

## Getting Started

### Prerequisites

Make sure you have:

- Node.js 20+
- Bun
- PostgreSQL
- Git

### 1. Clone the Repository

    git clone https://github.com/nabilaminhridoy/portfolio.git
    cd portfolio

### 2. Install Dependencies

Using Bun:

    bun install

Or using npm:

    npm install

### 3. Configure Environment Variables

    cp .env.example .env

Update `.env` with your local PostgreSQL database and application configuration.

### 4. Generate Prisma Client

    bun run db:generate

### 5. Push Database Schema

    bun run db:push

### 6. Start Development Server

    bun run dev

The application will be available at:

    http://localhost:3000

### Database Seed

The repository includes database seed and utility scripts under:

    scripts/

Use the appropriate seed or utility script according to your local database setup.

## Deployment

This project is designed for production deployment using **Vercel** with a managed **PostgreSQL** database.

### Production Stack

| Service | Purpose |
|---|---|
| Vercel | Application hosting and deployment |
| PostgreSQL | Production database |
| Prisma | Database ORM |
| NextAuth.js / Auth.js | Authentication |
| Cloudflare Turnstile | Bot protection |
| SMTP | Email delivery |

### Deploy to Vercel

1. Push the project to GitHub.
2. Import the repository into Vercel.
3. Configure the production environment variables.
4. Connect a production PostgreSQL database.
5. Configure the production `DATABASE_URL`.
6. Configure `NEXTAUTH_URL`.
7. Configure a secure `NEXTAUTH_SECRET`.
8. Configure Turnstile if enabled.
9. Configure SMTP if email functionality is required.
10. Deploy the application.
11. Verify the production application and database connection.

### Required Production Variables

    DATABASE_URL=
    NEXTAUTH_URL=
    NEXTAUTH_SECRET=

### Optional Production Variables

    TURNSTILE_SITE_KEY=
    TURNSTILE_SECRET_KEY=

    SMTP_HOST=
    SMTP_PORT=
    SMTP_USERNAME=
    SMTP_PASSWORD=
    SMTP_FROM=
    SMTP_FROM_NAME=

### Production Database

After configuring the production database connection:

    bun run db:push:prod

Generate Prisma Client when required:

    bun run db:generate

### Production Build

    bun run build

For detailed deployment instructions, environment configuration, database setup, and production considerations, see:
